# Sécurité

La confidentialité des données est au cœur de TVTracker : aucune clé d'API, aucune donnée ne quitte votre serveur sauf les requêtes de catalogue (TVmaze, Wikipédia, iTunes).

## Signaler une vulnérabilité

- Ne publiez **pas** la vulnérabilité dans une issue publique.
- Utilisez la [signalisation privée de vulnérabilité GitHub](https://github.com/Estemobs/tvtracker/security/advisories) (Security tab → Report a vulnerability).
- Pour les problèmes sensibles, contactez directement le mainteneur via Discord.

Vous recevrez un accusé de réception sous quelques jours. Merci de ne pas exploiter la faille et de donner un délai raisonnable avant toute divulgation.
